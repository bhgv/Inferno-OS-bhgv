# Native64: полный Titlebar

Неизменённый `appl/lib/titlebar.b` принимается целиком: 7/7 тел вместо 4/7.
Classic Dis побайтно прежний, включая исходный массив 14 Tk-команд.

Добавлены три закрытые формы compiler IR:

* Массив String использует mapped 8-байтные элементы. Создание и обычная
  индексация используют существующий root-array механизм; индекс локального
  String массива потребляется непосредственно следующей операцией.
* Индекс String массива передаётся в аргумент локального вызова (роль 74)
  или участвует в конкатенации импортированного аргумента (76). Адрес элемента
  хранится в немаппированном FP48 и потребляется следующим шагом, без вызова
  между ними. Владелец остаётся корнем. Для глобального массива compiler и
  module builder запрещают замену корня и выдачу адреса корня другим вызовам;
  обычная standalone индексация разрешена только для локального владельца.
* Конкатенация String — последний аргумент локального вызова (75). Проверены
  карты обоих источников, pending callee, позиция аргумента и границы кадра.

Частный Native64ModuleSpec получил ограниченный initializer плоских плотных
String массивов. Проверяются mapped MP слот, уникальность, отсутствие
пересечений со строками/таблицами, точные смещения элементов, UTF-8 и бюджет.
Доверенный callback создаёт свежий mapped pointer-array, аналогично
существующему callback конструктора String. Массив публикуется в уже
закреплённом MP до выделения его строк: ошибка
освобождает весь частично построенный массив. Это не новый формат Dis и не
разрешение произвольных ADT/вложенных массивов.

## Исполнение

`native64-titlebar-module.py` строит и исполняет весь исходник. Канонические
frame/signature данные получены из .m; независимый classic decoder проверяет
операнды, таблицы, exports, строки и исходный статический массив. Обнаружены
108 искажений новых инструкций и 10 искажений variadic records.

2112 процессов C/JIT охватывают все 64 сочетания флагов при квантах 1/3/1000:
init, new, sendctl, title, settitle и minsize; частный cmd исполняется через
оригинальные вызовы. Проверяются все 14 исходных команд, дополнительные
кнопки и pack-команды, точные строки передачи/заголовка, канал namechan и
все динамические имена виджетов minsize. Rect.dx/combine/size взяты из
производственного geom.c. Используются реальные VM массивы, строки,
конкатенации, канал и production arraycpy/newmp для экземпляров модуля.

Tk — контролируемый сервис, а не настоящий GUI. Ошибочный ответ Tk с
веткой диагностического fprint здесь не исполняется. Полное освобождение
массивов, строк, типов, модулей и каналов проверяется после каждого workflow.
Конструктор выдерживает все 89/90 отказов выделения C/JIT с атомарным
rollback. 26 вариантов метаданных отвергаются до выделения; допустимый пустой
статический массив также строится и освобождается.

ASan/UBSan проверяют положительный прогон и активные контроли: неверное
заполнение массива, неправильный индекс String аргумента и неправильный
источник локальной конкатенации. Тест включён в native64-port и оба задания
native64-typed-calls CI. Локальные результаты относятся к amd64; выполнение
arm64/riscv64 и Android этим тестом не подтверждается.

До настоящего окна AWM остаются Wmlib и Winplace и подключение реальных
сервисов. Полный Titlebar устраняет ещё одну зависимость, но не означает
готового AWM/Android GUI.
