# String → int и глобальный kbdfocus в native64

Checked LOAD-профиль допускает ICVTCW из прямого FP/MP String в локальный
FP int. Источник занимает 8 байт и должен быть GC root; результат занимает
ровно 4 байта и не может пересекать root. Эти условия проверяются до
выделения модуля. Используются существующие обработчик cvtcw/string2c и JIT;
семантика разбора чисел не меняется. Прямой результат в MP или inherited
result, преобразования String в big/real этим этапом не открываются.

Nil-сравнения дополнены прямым глобальным ref Wmsrv.Client. Компилятор
требует полный канонический Client: 52 классических / 96 native байт,
все поля и методы. Другие глобальные ADT, включая Draw.Image, остаются
закрыты. Сравнение использует существующие IBEQL/IBNEL и два GC root;
объект Client для сравнения не разыменовывается. Новый формат metadata
для произвольных ссылочных типов не вводится.

Проверки:

- `native64-string-word.py`: 1152 C/JIT запуска, nil, пустые строки,
  десятичные числа в диапазоне int32, хвосты, встроенный NUL, Rune и
  выделение/замена/повторное использование UTF-кэша; FP/MP, alias, повтор,
  ветвления и локальный CALL. 42 повреждения metadata в независимом oracle,
  80 отказов загрузчика до выделения, 23/24 точки отказа конструктора.
- Контрольные мутации должны обнаруживаться: снятие проверки source root,
  снятие проверки raw destination и запись 8 байт вместо 4. Последняя
  проверяется соседним живым локальным int.
- `native64-mp-client-nil.py`: 72 C/JIT случая, прямой/обратный eq/ne,
  живой/nil Client, четыре непрозрачных 64-битных значения указателя,
  включая значение с младшими 32 битами, равными nil. Фиктивные указатели
  не разыменовываются и убираются перед освобождением модуля. 24 повреждения
  независимого oracle, 17/18 точек отказа конструктора. Контрольная замена
  сравнения на 32-битное должна нарушить проверку результата.

Оба теста подключены к amd64 и arm64/riscv64 CI и общему native64-port.py.
Локальные прогоны этого этапа выполняются на amd64; наличие CI-задач не
означает, что arm64/riscv64 уже проверены в этой сессии.

На amd64 оба новых теста прошли UBSan и ASan+UBSan, включая контрольные
мутации. Регрессии форматтера (300 C/JIT запусков) и полей/каналов Client
(4032 запуска) прошли. Отдельная чистая сборка прошла console/pair boot
и 324 процесса настоящего Arg/emuinit с интерпретатором и JIT.

Настоящий awm.reshaped остаётся accepted целиком. awm.init проходит ICVTCW
на PC187 и nil-проверку kbdfocus на PC189. Следующий отказ — PC192,
`external-geometry-argument`: `wmclient->win.pointer(*p)` передаёт
Draw.Pointer по значению. Это отдельный номинальный тип, а не Rect,
несмотря на одинаковый размер 16 байт; его admission пока закрыт.

Классические Dis bytes и 32-битные пути сохранены. Графический AWM и
Android UI на этом этапе ещё не запущены.
