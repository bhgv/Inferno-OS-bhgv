# Native64: Point/Rect как результат локальной Limbo-функции

Настоящая fitrect из appl/wm/awm.b принимается checked-компилятором целиком.
handlerequest проходит прежний отказ PC506, включая передачу двух Rect,
методы Rect.dx/dy/size и возврат результата в локальный r. Новый отказ —
PC521 multi-callee на newrect. Сама newrect теперь проходит прежний отказ
aggregate-result и останавливается на PC1340: CONSM добавляет Window.r
в list of Rect. awm.init пока остаётся на PC303, поскольку handlerequest
ещё не принят целиком. Окно AWM и Android UI ещё не запущены.

Разрешены whole-value результаты канонических Draw.Point и Draw.Rect:

| Результат | Private contract | Body role | Ширина |
| --- | --- | --- | --- |
| Point | 96 | 247 | 8 байтов, два Word32 |
| Rect | 112 | 246 | 16 байтов, четыре Word32 |

Свежий результат локального CALL размещается в проверенной области FP
вызывающей функции, с выравниванием4. Это те же raw result contracts,
которые уже использовались для импортированных геометрических методов;
private function metadata теперь явно сохраняет соответствующий контракт.
Источник return может быть FP или MP. Nominal тип Draw.Point/Rect и полный
layout с Word32 leaves проверяются по compiler IR. Pointer и структурно
похожие ADT не допускаются. Прямой результат в MP и inherited forwarding
адреса через локальный вызов остаются закрытыми. Вложенные вызовы разрешены
через отдельный локальный результат и последующее полное копирование.

Return понижается в IMOVM в native result slot32; ширина остаётся8/16,
а не становится числом ссылок. CFG-проверка требует определённый результат
на каждом достижимом RET; целый raw copy отмечает результат определённым.
Raise не требует результата. Поля не записываются в результат по частям.
Существующий binder проверяет весь raw диапазон вызывающей функции.

Module preflight проверяет совпадение контракта вызывающего и вызываемого,
точный opcode/modes/width, границы источника, отсутствие GC-битов во всех
его байтах, result slot32 и отсутствие return copy внутри подготовки CALL.
Unclaimed IMOVM в result slot не допускается. Локальные аргументы и
локальный результат имеют отдельные проверки; возвращаемое значение
не принимается за аргумент следующего вызова. GC map не доказывает nominal
тип; это premise доверенного compiler IR, а не разрешение загрузки
произвольного native файла. Shared FlashVM wire ABI не меняется.

native64-local-geometry-results.py исполняет целую неизменённую fitrect,
извлечённую из awm.b, и настоящие Rect.dx/dy/size из geom.c. Проверяются
FP/MP источники обоих типов, локальные и вложенные вызовы, обе ветви return,
raise с освобождением exception owner, nil Window, выравнивание4, сохранение
остальных MP/caller/Window байтов, int32 границы и modular Word32 arithmetic.
Семантический oracle вычисляет fitrect по независимым осям с явной
модульной арифметикой; исходная геометрическая политика AWM не меняется.

Независимый classic-byte oracle повреждает каждый компонент return copy
и local result binding. Metadata повреждается до первого выделения,
конструктор проверяется во всех точках отказа. Для проверки полного raw
GC-диапазона есть изолированный producer без вызывающих функций: другая
проверка аргументов не может замаскировать пропущенную проверку return.
Активные контроли намеренно обрезают копирование и GC-диапазон и смещают
адрес результата. Тест включён в native64-port.py и обе секции typed-calls CI.
Classic Dis и 32-битный код сохраняются.

Локально amd64: 576 C/JIT сценариев под ASan+UBSan, 193 metadata refusals
до выделения, 102 повреждения независимого classic-byte oracle, 44/45 точек
отказа конструктора C/JIT модуля и три активных контроля. Регрессии проходят:
imported geometry results360 и local geometry arguments384 со всеми их
активными контролями. Сборка с чистого дерева проходит; реальный неизменённый
Arg/emuinit выполняет 324 C/JIT процесса. Новое выполнение на ARM64, RV64
и Android в этом локальном результате не заявляется.
