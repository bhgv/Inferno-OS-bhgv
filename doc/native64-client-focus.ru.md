# Native64: сравнение Client и строки cursor в setfocus

Настоящий setfocus проходит `old == new` на PC1189, сравнение содержимого
`old.cursor` и `new.cursor` на PC1201 и передачу `new.cursor` в wmctl
на PC1203–1207. Новый отказ — PC1210 indirect-or-reserved-operand:
IANDW над косвенным `new.flags`, маска Kbdstarted (2).
awm.init по-прежнему останавливается на вызове setfocus, PC210 multi-callee.
reshaped остаётся accepted целиком. Графический AWM и Android UI не запущены.

Добавлены три выбранные операции checked LOAD:

| Role | Операция | Проверка компилятора |
| --- | --- | --- |
| 231 | IBEQL/IBNEL двух прямых roots FP/MP | Один и тот же nominal Wmsrv.Client, полный layout обоих операндов |
| 232 | IBEQC/IBNEC: Client.cursor против прямого String FP/MP | Канонический Client, classic cursor20/native40, тип String |
| 233 | IMOVP Client.cursor в импортируемый кадр | Тот же owner/field proof, String-аргумент импортируемой функции |

Role231 сравнивает адреса объектов по всем 64 битам и не разыменовывает
Client. Nil, alias и различные живые объекты допускаются. Сравнения других
ADT, смешанных типов, произвольных полей или по порядку не добавляются.
Старые nil-проверки сохраняют прежние правила.

Role232 сравнивает содержимое строк существующими branchstring/stringcmp.
Она не заменяется сравнением адресов String. Источник косвенный FP/MP,
единственное поле — cursor40; второй операнд — прямой типизированный String.
Владелец и String должны быть отдельными проверенными GC root-слотами.
Nil String имеет штатную семантику stringcmp; nil Client вызывает unwind.
Проверка карты для этого пути отделена от старой проверки прямых строк.

У обоих сравнений target обязан лежать внутри функции, middle — внутри
полного 8-байтного root и не дальше 65535: регистр Inst.reg имеет 16 бит.
Оба root map и структурные условия проверяются до выделений. Сравнения
не могут быть частью подготовки CALL. Повреждённые теги у этих branch
форм также отвергаются до конструктора.

Role233 передаёт String существующим IMOVP с удержанием ссылки в кадре
импорта. Source owner обязан быть GC root; destination — полный root8
импортируемого кадра. Offset40, opcode, modes, spans и принадлежность
единственному внешнему callsite проверяются до выделений. Локальный CALL
с этой ролью закрыт в компиляторе и загрузчике. Возврат alias String и
unwind после ошибки импорта проверяются отдельно.

Это внутренний checked IR с premise о типах из компилятора; GC map сам
по себе не доказывает nominal тип объекта. Загрузка произвольного native
файла этим этапом не разрешается. Классические Dis bytes и 32-битные пути
не меняются; backend JIT и обработчики VM также не меняются.

Проверки на amd64:

- native64-client-compare.py: 432 C/JIT случая, FP/MP eq/ne, alias,
  разные объекты, nil, private CALL и шесть непрозрачных пар указателей.
  Одинаковые младшие 32 бита при разных старших должны давать неравенство.
  Фиктивные значения используются только в MP probe без dereference/retain
  и восстанавливаются до освобождения; сборщик в таком probe не запускается.
  Три сочетания FP/MP получены из compiler trace; четвёртый mode проверяется
  симметричной перестановкой сравниваемых roots в копии checked metadata.
  Oracle обнаруживает 72 повреждения, loader — 192 до выделений;
  constructor rollback проверен в 36/37 точках C/JIT.
- native64-client-cursor.py: 576 C/JIT случаев, четыре сочетания owner/value
  FP/MP, nil/empty, ASCII/Rune/Unicode, embedded NUL, одинаковое содержимое
  разных String, nil владельца с обеих сторон. 48 повреждений oracle,
  128 отказов до выделений, 25/26 точек rollback. Используются настоящие
  branchstring/stringcmp, не тестовая реализация сравнения.
- native64-client-cursor-args.py: 192 C/JIT случая, FP/MP owner, receiver
  перед String, alias result, nil-owner и ошибка внутри импорта после
  передачи аргумента. 24 повреждения oracle, 64 отказа до выделений,
  26/27 точек rollback. Приёмник контролируемый; реальный wmctl не выполняется.

Во всех трёх тестах проверяются caller guards и полное освобождение heap,
кадров, String и module links. Активные контроли обнаруживают усечение
указателя, подмену String content на identity, неверный offset, снятие
owner map и снятие 16-битного ограничения middle. Sanitizer crash не
засчитывается. Gate подключены к обоим путям CI и native64-port.py;
локальный прогон не означает выполнения arm64/riscv64 CI или Android UI.

Все три gate прошли ASan+UBSan (`detect_leaks=0`, с явными счётчиками
владения), включая активные контроли. Регрессии ссылочных полей2736 и
форматтера300 прошли со своими контрольными мутациями. Отдельная чистая
amd64 сборка прошла console/pair boot и 324 процесса настоящего Arg/emuinit.
