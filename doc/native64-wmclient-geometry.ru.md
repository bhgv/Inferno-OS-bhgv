# Native64: геометрия Wmclient.Window

Полный исходник `appl/lib/wmclient.b` теперь принимает 7/21 тел вместо 5/21.
Неизменённые `Window.screenr` и `Window.imager` исполняются в C/JIT с
производственными Rect.dx/dy/inset из `libinterp/geom.c`.

## Изменения

После проверки полного nominal Wmclient.Window (104 classic байта,
128 native байт, 26 листьев, GC-карта 92/c4) разрешены все 20 скалярных
Word32-полей. Проверяются точные classic/native смещения; шесть GC roots
исключены из множества скалярных полей. Поддержаны обычные FP/MP чтения,
записи, арифметика и сравнения, включая неявный второй операнд compound
операции. Новые частные аннотации — 88/89.

Аннотация 86 переносит Word32-поле Window в скалярный аргумент проверенного
CALL/MCALL, в том числе `Rect.inset(w.bd)` и `Rect.inset(-w.bd)`. Runtime
проверяет единственную enclosing call-site, карты владельца и аргумента,
границы и сырую роль целевого слота до выделения памяти.

Возврат внешнего Draw.Point/Rect может использовать результат вызывающего
модуля. Для этого введён отдельный callerresultcontract в частном trusted-C
Native64TypedCall: совпадения контракта callee недостаточно. Module builder
проверяет контракт текущей функции и передаёт его материализатору;
изолированный API без caller proof отказывает атомарно. Локальные
inherited geometry-вызовы остаются закрыты. Обычный Dis не меняется.

Чтение скалярных Image.depth/chans.desc/repl расширено на точные смещения
32/36/40 после существующей полной проверки Draw.Image.

## Проверка

Новый `native64-wmclient-geometry.py` выполняет 1662 C/JIT вызова с квантами
1/3/1000: все 20 полей Window, FP/MP-владельцы, крайние Word32, три поля
настоящего 72-байтного Image fixture, nil-владельцы, сохранность соседних
байтов/roots и полное освобождение. Оригинальные screenr/imager проверяются
на обычных, вырожденных и крайних прямоугольниках, наличии/отсутствии
заголовка, положительной/отрицательной границе и переданном результате Rect.

Fixture содержит два неизменённых метода, 42 Window helper, три Image
helper, специальный init для таблицы Draw и отказывающие неиспользуемые
публичные тела. Частные неиспользуемые тела удаляет обычный compiler.
Оба выбранных тела дополнительно проверяются в полном исходном Wmclient.
Канонические кадры импортов берутся из сгенерированного Draw header.

Независимый source oracle обнаруживает 288 искажений. Runtime отвергает
337 вариантов метаданных, включая 48 карт владельцев, до выделения.
Конструктор проверен на 138/139 точках отказа C/JIT. Проверен отдельный
атомарный отказ private materializer без caller proof. Активные контроли
подменяют смещение скалярного поля и удаляют проверку caller contract.
Посторонний record и namespace для скалярного владельца отклоняются.

На amd64 прошли UBSan и ASan/UBSan с активными контролями. LeakSanitizer
отключён из-за ptrace среды (detect_leaks=0); внутренние проверки полного
retirement включены. Чистая сборка прошла console, pair boot и emuinit boot.
Прошли регрессии geometry-results, local-geometry-results, Window fields,
Window geometry args, полный Wmsrv init/wm и AWM call cluster, включая
их активные контроли. Тест добавлен в native64-port и оба задания
native64-typed-calls CI.

## Следующие ограничения

Это ещё не подключение полного Wmclient к оконному серверу или настоящее
окно AWM. Следующие отказы включают Window geometry arguments/results,
Tk geometry results, внешний tuple-результат qword/s2r и клиентский обмен
изображениями. Wmsrv остаётся 34/34. Android и выполнение новых путей на
arm64/riscv64 в этом блоке не проверялись. 32-битные пути сохранены.
