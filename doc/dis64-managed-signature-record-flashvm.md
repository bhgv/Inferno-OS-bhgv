# FlashVM review of the managed signature record

The proposed exact-length record with a distinct version, parameter count, result expression and ordered parameter expressions works for the first String pilot. Use symbolic String and List(String) in fixture construction. Reject any second list level, wrong child, missing word, trailing word or swapped direction. Keep scalar version 1 unchanged and leave numeric IDs open until shared positive and refusal fixtures are available.

Frame verification is a separate gate. Compare the selected generated export's extent and map, keep the transient result address out of the GC map, and require the caller-owned result slot to be mapped and initially nil. The type match must distinguish the two symbolic signatures before call-frame construction.
