## Producer and raw authority

Existing -64c now accepts a separately bounded importing command: one argument-free
void init, one constant path and module local, scalar imported calls and linear
scalar continuations. The compiler extends only its internal typed lowerer with
an explicit client mode; ordinary body/external reports retain their old mode.
Final compiler LDT records and `.m` declarations supply exact existing signaturev1
and ordinals. Limbo narrowing remains normal: this file contains the complete
selected LDT, while0180's optional C header still requests the complete `.m`.
No classic hash is guessed or used as structural authority.

The writer relocates the one module root/path into a fixed mapped MP, uses the
existing result-address tail protocol and emits existing five-section framing.
It runs dis64clientcheck before the sole output Bwrite. Unsupported source emits
no partial payload. The path is hydrated from String pool1 by this private Inferno
admission shape; this is not a new general managed DATA initializer agreement.

The allocation-free raw checker independently binds Module/Code/Types/Imports/
Strings, proves exact scalar frame/map and MP root roles, complete decoded code,
all ILOAD/MFRAME/argument/result/MCALL islands and definite scalar initialization.
Scalar spans cannot overlap/change kind. No branch, general reference access,
Frame64-header scalar access, unsupported opcode or unmatched prepared frame is
admitted. Only one interface/table is represented;64 signatures/parameters and
256 instructions/64 scalar spans bound work. Failed output publication is atomic.

This is no general untrusted managed-code admission. The accepted caller has no
argument/reference results, additional functions, handlers, branches/loops,
module globals or extra paths. Producer caps are128 original instructions and4096
frame bytes. Arithmetic fused into prepared arguments remains refused. All such
boundaries are explicit in the RU/EN tutorial.

## Runtime and namespace

prepare64calls discriminates the structural client shape separately from old
executable call images. Complete raw proof precedes VM owner creation. The protected
constructor owns Types/maps/code/name/path/MP, an actual filename String and copied
structural requests. MP is pinned through construction/JIT; every failure removes
only acquired roots and retires all partial owners. On success there is no retained
temporary pin: publication must precede another collecting operation, as ordinary
parsemod immediately registers the Module under exclusion. MP clone/startup rules
are the existing production ones.

Only this checked constructor sets native-only bit29 and its trusted owned-import
reader callback. Neither is decoded from file flags. No Module/Frame64/Modlink
layout, public section/opcode/signature ID, wire version or vendor pin changes.
The reader helper is shared across translation units and has a disabled stub;
trusted embedding installation retains its prior ownership/JIT contract.

Actual ILOAD uses0181 root publication/pin retirement and0180 fresh uncached
namespace admission plus0179 whole-provider proof. File-client JIT requests follow
host cflag at LOAD; dontcompile is rechecked after I/O. All serialized signatures
are matched, including equal-width Big/Real distinctions. No implicit library
init or builtin `$Sys`/`$self` admission is added. Default startup still refuses.
