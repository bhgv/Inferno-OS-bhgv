# Числовая голова списка в аргументах native64

Роль 253: 0–32 TAIL, HEADP в FP root-слот компилятора, CVTCW в raw Word32 аргумента импортированного кадра, затем readonly nil clear. Поддержаны отдельные int-аргументы и поля литеральных Draw.Point/Rect; источник списка строк — FP/MP.

Проверяются типы, исходные смещения, точный порядок, карты GC источника и временного слота, отсутствие GC-битов у всех четырёх байт результата, единственный внешний call site и границы кадра. Произвольные вычисления при подготовке аргументов не разрешаются. Используется существующий OP(cvtcw); String удерживается до преобразования, ошибки проходят через обычное освобождение кадра.

utils/tests/native64-int-head-args.py исполняет настоящий cvtcw и Point.sub/mul/add из geom.c: 396 сценариев C/JIT, FP/MP, повторные вызовы, короткие списки, nil-головы, отрицательные и граничные Word32, Rune-строки, ошибки cache/callee и смена quantum. Проверяются точные координаты, соседние байты аргумента, очистка root-слота и полное освобождение. Oracle отвергает 360 повреждений; загрузчик — 540 вариантов метаданных до выделений. Проверены все точки отказа создания модуля (32/33 для C/JIT). Три активных контроля: неправильное смещение координаты, пропуск очистки и запись восьми байт вместо четырёх.

В настоящем appl/wm/awm.b handlerequest проходит PC596–606, включая Point(int hd args,int hd tl args).sub(w.r.min). Следующий отказ — PC607 multi-callee при вызове dragwin. dragwin останавливается на PC859 context-field-roles; sizewin — PC901 load-byte-array-class. awm.init остаётся на PC303 multi-callee. Это продвижение компилятора и runtime fixtures; графический AWM и Android UI ещё не запускались.

Классический Dis и 32-битные реализации сохранены.
