# Все очереди Wmsrv в native64

Проверены все 13 неизменённых методов Iqueue, Squeue и Ptrqueue из
`appl/lib/wmsrv.b`: put/get/peek/nonempty для каждой очереди и Ptrqueue.flush.
Их исходные тела переносятся в исполняемый тестовый модуль без редактирования;
отдельно проверяются эти же методы внутри полного исходника Wmsrv.
Classic Dis с diagnostic lowering и без него совпадает побайтово.

Общие изменения:

- nil-сравнения для списков int и канонических ref Draw.Pointer;
- cons/head/tail для Pointer-списков с 8-байтными GC-корнями;
- сравнение Word32 поля Pointer с raw Word32 в FP/MP;
- полное копирование четырёх Word32 канонического Pointer между heap owners;
- выделение закрытых mapped records непосредственно в MP-корни;
- уникальные имена генерируемых функций по полному имени метода, чтобы
  Iqueue.get/Squeue.get/Ptrqueue.get не сталкивались в одном C-модуле.

Новые private annotations 138/139 различают сравнение поля и копию Pointer.
Чтение полей ограничено buttons/xy.x/xy.y/msec, размер копии строго 16 байт.
FP/MP ячейки владельцев должны быть GC-корнями; средний Word32 операнд
сравнения должен оставаться raw. Это не общий доступ к произвольным ADT.

Проверка `utils/tests/native64-wmsrv-queues.py` исполняет 25 тел: 13 исходных
методов и 12 тестовых публичных точек входа. 396 публичных вызовов идут через
настоящие MFRAME/MCALL, C/JIT и кванты 1/3/1000, включая расширение стека.
Проверяются FIFO, повторный peek, пустые очереди, nil/empty/Unicode строки,
int32 границы, смена кнопок и слияние Pointer-событий с сохранением идентичности
объекта и всех четырёх слов, flush и последующее добавление.
Семантика исходного flush сохранена: last не очищается этим методом.

Дополнительно: 330 независимых повреждений отчёта, 330 отказов runtime
метаданных, 7 отказов GC-карт до выделения памяти, все 51/52 точки отказа
C/JIT конструктора и полное освобождение объектов. Активный контроль
сокращает Pointer copy до 8 байт и обязан обнаружить неверные xy.y/msec.
Прогон ASan/UBSan проверяет ту же матрицу.

```sh
python3 utils/tests/native64-wmsrv-queues.py --limbo /path/to/limbo
```

Полный Wmsrv теперь принимает 16/34 checked IR тел, Wmclient остаётся 5/21.
Полное исполнение этих двух библиотек, загрузка их файлового графа и окно AWM
ещё не подтверждены. 32-битный путь и classic Dis сохраняются.
