# Draw and Prefab native pointer maps

Run `python3 libinterp/tests/gui-type-maps.py` from the repository root.
`CC` and `CFLAGS` select the host compiler and flags; UBSan is enabled by default.
`DRAW_MAP_SOURCE` and `PREFAB_MAP_SOURCE` select alternate source revisions.
`GUI_MAP_CASE=draw` or `prefab` selects one group.

The fixture extracts actual Draw wrapper declarations, both module descriptor
initializers and production descriptor/heap/map initialization, pointer-copy
reference retention and pointer release. Generated public records and actual
Prefab private wrappers provide the native C layouts. Tests compile the same
private native-map helper used by the modules. Allocators, builtin registration,
collector callbacks and final destruction dispatch are bounded adapters. Native
image/display/font/compound finalizers and rendering are not executed.

There are 1,040 scenarios per WORD64/WORD32 configuration, or 2,080 executions.
WORD32 changes the VM word declaration while retaining host-native pointers;
it does not emulate a separate 32-bit pointer ABI. The suite covers seven record
descriptors and thirty managed fields. Every combination of nil/populated fields
is checked, with both independent and shared children and both destruction orders
of original/copy. Real `incmem` and `freeptrs` must balance all references.

Every mapped field must initialize to H. Poisoned scalar, padding and private
native/alias bytes must remain untouched. Every descriptor and heap allocation
has exact guards, and all blocks and type/child references must be released.
ASan+UBSan passes the complete matrix with stack instrumentation enabled:

```
CFLAGS='-O1 -g -fsanitize=address,undefined -fno-sanitize-recover=all' python3 libinterp/tests/gui-type-maps.py
```

LeakSanitizer inspection is unavailable; explicit live-block accounting covers
all fixture allocations. There are no injected errors or nonlocal jumps in this
suite. GUI type-map checks are also included in the shared host checkpoint.

Previously, Prefab_Layout used a fixed 24-byte descriptor, which cannot describe
six native eight-byte pointers. Draw font/image and Prefab element/compound maps
also used generated four-byte pointer positions, which differ when VM words and
native pointers have different sizes. Maps now use actual field offsets, while
the layout descriptor uses sizeof(Prefab_Layout). Public managed fields remain
the owners; private native pointers and aliases remain outside these maps.
Generated bytecode layout constants are unchanged, and this fix does not establish
a complete native 64-bit ABI or a working 64-bit JIT.

Parent-source substitution reproduces the layout size failure. Correcting only
the old Prefab layout size still fails its WORD32/native-pointer64 map checks.
Old Draw maps independently fail the same mixed-width model. Adjacent Prefab
selection and Draw image/cache tests run separately. Host Draw syntax checking
retains pre-existing SVG qsort callback warnings. The checkout lacks the generated
prefabmod.h needed for a full Prefab translation-unit build; its changed production
initializer and real records are compiled by this fixture. No full GUI/Inferno
build or target JIT execution is claimed.
