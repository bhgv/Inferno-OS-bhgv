# Sys.dirread native record layout and error cleanup

Run `python3 libinterp/tests/sys-dirread.py` from the repository root.
`CC` and `CFLAGS` choose the host compiler and flags; UBSan is enabled by default.
Set `DIRREAD_SOURCE` to an alternate `inferno.c`, or `DIRREAD_CASE` to `layout`,
`content` or `failure` to select a subset.

The fixture extracts each platform's real `sysinit`, `unpackdir`, `Sys_dirread`
and `kprotect`, plus production VM array initialization/release, pointer maps,
string constructors, UTF decoding and `retstr`. Actual Sys frame, directory,
array and heap declarations supply their native layouts. Descriptor construction,
native directory I/O, scheduler transitions and exact guarded allocation are
bounded adapters. Both runtime sources use host emulator error-stack declarations;
this is not a kernel boot or a complete Inferno build.

Each emulator/kernel and WORD32/WORD64 configuration executes 1,197 checks,
for 4,788 executions. The word models retain host pointers; they are not two
native pointer ABIs. Tests check nil UID fields, empty strings, multibyte and
supplementary-plane text, every metadata field, wide paths and file lengths,
multiple records, EOF and native errors. The old result contains a string owner
and must be released on every path, matching the existing dirread return policy.

Each allocation in results containing up to sixteen records is failed in turn,
including every name/UID/GID/MUID conversion. Failures must return `(-1,nil)`,
retain the original error identity, balance runtime error frames and scheduler
state, release partial arrays and strings, and free the native directory buffer.
Poisoned payloads check pointer-map initialization; exact allocation guards and
explicit live-block/type-reference counters check ownership. ASan can be combined
with UBSan. LeakSanitizer inspection is unavailable in the sandbox; all heap
blocks are tracked explicitly.

The directory descriptor now uses `sizeof(Sys_Dir)` and conversion advances by
native typed records. Generated bytecode layout constants are unchanged; this
fix alone does not establish a complete 64-bit VM or JIT ABI. On the existing
32-bit ABI the native record size remains the historical 64 bytes.

Parent-source probes reproduce the descriptor-size failure directly. Applying
only its descriptor-size correction still reproduces record overlap in the
content subset. Applying both layout corrections to the parent source isolates
its prematurely removed error frame: field-allocation errors escape instead of
cleaning up and returning the documented `(-1,nil)` result.

For packed fixed frames, callback capture, full native counts and descriptor
boundaries, see [stream and directory capture](README.sys-stream-directory-capture.md).
